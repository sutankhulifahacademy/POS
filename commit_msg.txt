Add paket/bundle product type with composition items

Products can now be either "regular" or "paket" (bundle). A paket is a
collaboration of multiple products, each with its own selling price.

Database:
- products.product_type VARCHAR(20) DEFAULT 'regular'
- products.bundle_items JSONB DEFAULT '[]' (array of
  {product_id, name, price, quantity})

Backend:
- ProductCreate/ProductUpdate models accept product_type + bundle_items
- POST /products and PUT /products/{id} persist both fields

Frontend (Products.js):
- Product type selector: "Produk Reguler" vs "Paket / Bundle"
- When "paket" is selected, a "Komposisi Paket" section appears:
  - Dropdown to pick from existing regular products
  - Auto-fills product name and unit price on selection
  - Quantity field per bundle item
  - Subtotal per row (price x qty)
  - Total modal value of all bundle items
  - Add/remove bundle item rows
- Product table shows "Paket" badge or "Reguler" label
- Paket products are excluded from the bundle item dropdown (no nested
  bundles)

The selling price of the paket is set in the existing "Harga Jual" field
and can differ from the sum of component prices (allowing bundle
discounts or markups).

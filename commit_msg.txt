Add file upload system with static serving for images

## New: POST /api/uploads endpoint

Added a real file upload endpoint that saves images to the server:

- Endpoint: POST /api/uploads (multipart/form-data)
- Accepts: jpg, jpeg, png, webp, gif, svg
- Max size: 5MB
- Returns: { "url": "/api/uploads/<uuid>.<ext>", "filename": "..." }
- Auth required (any logged-in user)

Files are stored in /app/uploads/ inside the backend container.

## New: Static file serving

Mounted StaticFiles at /api/uploads/ so uploaded images are
publicly accessible via URL:

  GET /api/uploads/<filename>  →  serves the image file

No authentication needed for GET (images are public).

## Docker volume for uploads

Added uploads_data volume to docker-compose.yml so uploaded files
persist across container restarts:

  volumes:
    - uploads_data:/app/uploads
